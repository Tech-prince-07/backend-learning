

# 🚀 Student Registration Portal

A backend-focused web application built as part of my **Backend Development Learning Journey** using **Node.js** and **Express.js**.

> **This project represents my learning phase.** My primary goal was to understand backend architecture, routing, controllers, request handling, and application flow by building a complete project from scratch.

---

## ✨ Features

* ✅ Student Registration Form
* ✅ User Login Page
* ✅ Contact Us Page
* ✅ About Page
* ✅ FAQ Page
* ✅ Fully Functional Navigation
* ✅ Express Routing
* ✅ Controller-Based Architecture
* ✅ Static File Serving
* ✅ Form Submission Handling

## 📌 Current Status

* All pages are connected through Express routing.
* All buttons and navigation links are functional.
* The application works as intended for its current scope.
* The submitted form data is currently displayed in the terminal/code editor as a JavaScript object, making it easy to verify and understand how Express handles incoming request data.
* Database integration has **not** been implemented yet because I am currently learning databases.

🚀 **MongoDB integration, authentication, validation, session management, and additional backend features will be added in upcoming versions as I continue learning.**
